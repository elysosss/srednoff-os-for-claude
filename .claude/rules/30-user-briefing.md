# 30-user-briefing.md

> Канонический источник. Развёрнутая версия — `.agent/USER_BRIEFING.md`; при правке одного файла проверь и обнови второй.

Задавай максимум 5 вопросов.

Задавай только блокирующие вопросы. Блокирующий — тот, без ответа на который получится неправильный
продукт: кто целевой пользователь; какой стек строго обязателен; где деплоить; какие
доступы/MCP/коннекторы можно использовать и что нельзя менять; какие платежи, бюджет и лимиты; какие
юридические и security-ограничения. Остальное — assumption.

Если вопрос не блокирует работу, сделай assumption:

```md
Assumptions:
-
```

Не спрашивай то, что уже понятно из контекста.
Если пользователь просит работать без вопросов — работай по assumptions.
