# D10: Глоссарий и линтер терминов

> Статус: DRAFT
> Тип: спека-набросок
> Модуль E1: `glossary-lint` (режимы `off | warn | enforce`, по умолчанию `off`); шаг гейта 1 в CI через `ciTemplates` D8
> Зависит от: E1, D1 (`docs/glossary.md` создаёт `artifacts init`), D5 (раздел `## Публичный API` в `CONTRACT.md` — объявленная публичная поверхность модуля), D6 (Q1 — язык ядра; модули и адаптер Terraform), D7 (`testGlobs` — что не считать API), D8 (доставка в CI, контроль правок глоссария)   Блокирует: D9 (счётчик новых неизвестных терминов)

## Goal
`docs/glossary.md` в машиночитаемом формате задаёт канонические термины и запрещённые синонимы; линтер разбирает идентификаторы **публичного API** новых и переименованных символов, режет их на слова и сообщает: запрещённый синоним — ошибка (настраивается), неизвестный доменный термин — предупреждение.

## User value
Бриф §1: «агенты любят плодить синонимы» — `stop`, `station`, `halt` для одного понятия через полгода делают код нечитаемым и для людей, и для следующих агентов (больше контекста на тот же смысл). Закрыто, когда синоним из глоссария не проходит CI в публичном API, а новые доменные слова всплывают списком «внести в глоссарий или переименовать».

## Non-goals
- Не проверяем приватные имена, локальные переменные и тела функций — только публичную поверхность.
- Не проверяем русскую прозу спек по умолчанию: морфология ломает точное сравнение токенов (см. Risks); опциональный режим — только для терминов в обратных кавычках.
- Не орфография и не инклюзивный язык — для этого есть `typos`, `codespell`, `woke`.
- Не генерируем глоссарий автоматически; `--suggest` лишь печатает кандидатов.

## Current state
В OS нет ничего про термины потребителя. Близкое — `validate-docs.{ps1,sh}` (проверки документов OS, не проекта). Скилл `technical-writer-agent` — проза.

## Assumptions
- `ASSUMPTION:` снятие английского множественного числа тремя правилами (`-ies→-y`, `-es` после `s/x/z/ch/sh`, `-s`) плюс колонка `forms` для исключений даёт на словаре проекта владельца меньше 5 % ложных «неизвестных». Проверить: прогон `--all` на проекте, ручная разметка 100 токенов.
- `ASSUMPTION:` регэксп-адаптеры (Go: заглавная буква у `func/type/var/const`; Rust: `pub` у `fn/struct/enum/trait/type/const/mod`; TS: `export`) покрывают ≥ 95 % публичных символов без макросов и реэкспортов. Проверить сравнением с `go doc -all`/`cargo doc` JSON на двух проектах; при провале — ast-grep как точный адаптер.

## Questions

## Architecture (дизайн)
1. **Парсер глоссария.** Раздел `## Термины` — таблица; раздел `## Общие слова` — список разрешённых недоменных токенов проекта; всё прочее в файле — свободный текст для людей. Проверки целостности: один `code` в двух терминах, синоним одного термина совпадает с `code` другого, пустой `code` → код 2.
2. **Адаптеры публичной поверхности** (выход — `[{name, kind, file, line}]`): `python` (stdlib `ast`: символы модуля без `_`, `__all__` если задан, публичные методы и поля публичных классов, в модулях без `_` в пути); `go`, `rust`, `ts` — регэкспы (допущение), ast-grep по флагу; `terraform` — `variable`/`output` модуля (переиспользует адаптер D6); область — модули D6 (каталоги с `CONTRACT.md`); если `## Публичный API` модуля (D5) перечисляет пути — берутся только они, если символы — только они; без D5/D6 — все файлы языка вне `testGlobs` D7.
3. **Токенизатор:** разбиение по `_ - .`, границам camelCase и акронимов (`HTTPBusStopClient → http bus stop client`), цифры отбрасываются, нижний регистр, снятие множественного числа, затем жадное сопоставление многословных `code`/синонимов (`bus_stop` как один термин).
4. **Классификатор токена:** `code` глоссария → ок; синоним → `forbidden` с подсказкой канона; встроенный стоп-список программистских слов (≈ 500: `get, set, list, id, config, handler, …`) или `## Общие слова` → ок; иначе → `unknown`.
5. **Область по умолчанию — дифф:** только публичные символы, которых нет в base (новые и переименованные), поэтому старый код не шумит; `--all` — полный аудит для первой сборки глоссария; `--suggest` печатает частотный список `unknown` для человека.
6. **Выход в D9:** число новых `unknown` за прогон в артефакте.
Отвергнуто: словарь английского языка вместо стоп-листа (любое английское слово стало бы «известным», и `station` не отличался бы от `stop`); LLM-классификатор «доменное ли слово» (недетерминирован).

## API contracts (интерфейсы и форматы)
Формат `docs/glossary.md`:
```md
## Термины
| Термин | code | Запрещённые синонимы | forms | Определение |
|---|---|---|---|---|
| Остановка | stop | station, halt | | Точка посадки пассажиров |
| Вместимость | capacity | size, volume | | Максимум пассажиров на остановке |
| Автобусная линия | bus_line | route | | Упорядоченный список остановок |

## Общие слова
tick, snapshot, scheduler
```
Конфиг `.claude/os-modules/glossary-lint/config/project.json` (коммитится, файл гейта D8): `{"forbidden": "error", "unknown": "warn", "scope": "diff", "adapters": ["python","go","rust","ts","terraform"], "prose": "off"}`. Команда `glossary-lint.{ps1,sh} [-Base REF] [-All] [-Suggest] [-Json]`. Коды: `0` нет ошибок (предупреждения допустимы); `1` есть `forbidden` при серьёзности `error`; `2` глоссарий невалиден; `3` нет файла глоссария при включённом модуле. JSON: `{schema, findings:[{kind:"forbidden|unknown", token, canonical?, identifier, file, line}], unknown_new: n}`.

## Data model / migrations
Глоссарий — документ проекта (D1). Состояния у линтера нет. Смена формата таблицы — через номер в HTML-комментарии `<!-- glossary-schema: 1 -->` в начале файла; нет номера — схема 1.

## Security model
Угроза — агент «лечит» ошибку правкой глоссария (добавил синоним в канон или удалил запрет): глоссарий под CODEOWNERS через D8, правка → high-risk и аппрув человека. Линтер читает только исходники, код проекта не исполняет. Не защищаем от синонимов в приватных именах и в строках/комментариях — сознательно вне области.

## Risks
| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Поток `unknown` на старте делает предупреждения шумом | высокая | среднее | область `diff`; `--suggest` для первичной сборки глоссария; `unknown` не бывает ошибкой |
| Морфология: `stops`, `stopped`, `stopping` | средняя | низкое | правила множественного числа + колонка `forms` |
| Русская проза в спеках — вне проверки | высокая | низкое | честно в Non-goals; опционально только `backtick`-термины |
| Реэкспорты и макросы проходят мимо регэкспов | средняя | среднее | ast-grep-адаптер по флагу |

## Acceptance criteria
1. Запрещённый синоним в новом публичном символе → код 1 и подсказка — S1, S4.
2. Неизвестный термин → предупреждение, код 0 — S2.
3. Приватные символы не проверяются — S3.
4. Противоречивый глоссарий → код 2 — S5.
