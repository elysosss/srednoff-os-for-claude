## Почему behave, а не только `run-evals`

`scripts/run-evals.{ps1,sh}` гоняет табличные фикстуры против одной функции (роутер, паттерн).
Расширения вроде F1 — это **сценарии**: «модель прочитала файл → видит плейсхолдер → правит →
на диске оригинал». Такое естественно выражается в Gherkin. behave берём для сценариев
модулей; табличные фикстуры правил остаются в `registry/evals/` и `run-evals`.

Зависимость: `behave` в системе не установлен (проверено: `python -m behave` → No module
named behave; Python 3.14.5 есть). Ставится в venv модуля, а не глобально — установка
зависимостей требует явного согласия владельца.
